## 👑 नया समर्पित एडमिन पैनल (Dedicated Admin Panel)

हेडर में **"एडमिन (Admin)"** बटन पर क्लिक करके सुरक्षित पिन दर्ज करके प्रवेश करें:
- **डिफ़ॉल्ट सुरक्षा पिन**: `1234` (या `admin` / `kisan2026`)

### 1. 🔌 बहु-एपीआई एकीकरण केंद्र (API Management Hub)
एडमिन एक ही डैशबोर्ड से अनेक बाहरी APIs को जोड़, टेस्ट और प्रबंधित कर सकता है:
- **लाइव मौसम API**: Open-Meteo, OpenWeatherMap (तापमान, वर्षा, हवा की गति)
- **सरकारी मंडी भाव API**: Data.gov.in / Agmarknet (दैनिक APMC रेट्स)
- **एआई फसल डॉक्टर API**: Google Gemini AI Vision (रोग व दवा पहचान)
- **एसएमएस व व्हाट्सएप गेटवे**: MSG91 / Twilio (आपातकालीन अलर्ट व OTP)
- **भुगतान गेटवे API**: Razorpay / UPI Escrow (0% दलाली डायरेक्ट खरीद)
- **कस्टम REST API**: नई API का नाम, एंडपॉइंट URL, API Key, HTTP मेथड (GET/POST) दर्ज कर **लाइव पिंग (Ping API)** टेस्ट की सुविधा।

### 2. 👥 किसान एवं ग्राहक प्रबंधन (Customer & Farmer CRM)
- सभी पंजीकृत किसानों, व्यापारियों (Traders) और कृषि वैज्ञानिकों की विस्तृत सूची।
- **KYC सत्यापन**: 1-क्लिक में किसान का आधार व खतौनी सत्यापन टॉगल करें।
- **खाता स्थिति**: सक्रिय (Active) या निलंबित (Suspended) करें।
- **नया किसान जोड़ें**: नाम, मोबाइल, राज्य, जिला, कृषि भूमि और मुख्य फसलों के साथ सीधे पंजीकरण।
- **CSV निर्यात**: एक क्लिक में समस्त किसान डेटा का बैकअप CSV फ़ाइल के रूप में डाउनलोड करें।

### 3. 🏛️ मंडी भाव संपादक (Live Mandi Rates Manager)
- किसी भी मंडी जिंस (गेहूं, धान, सरसों, प्याज आदि) का मॉडल भाव, न्यूनतम/अधिकतम दर सीधे संपादित (Edit) करें।
- नई फसल व स्थानीय मंडी का भाव तुरंत जोड़ें और लाइव प्रकाशित करें।

### 4. 📢 सामूहिक किसान प्रसारण (Emergency Broadcast & Alert Center)
- मौसम आपदा (जैसे ओलावृष्टि, आंधी, बेमौसम बारिश) या टिड्डी प्रकोप का आपातकालीन अलर्ट तुरंत सभी किसानों की स्क्रीन पर प्रसारित करें।

## ✨ किसान भाइयों के लिए मुख्य सुविधाएं (Farmer Features)

1. **🌐 द्विभाषी इंटरफ़ेस**: हिंदी और English में पूर्ण समर्थन।
2. **🌦️ सजीव मौसम व कृषि एडवाइज़री**: लाइव तापमान, नमी, हवा की गति एवं **कीटनाशक छिड़काव मीटर**।
3. **🏛️ ताज़ा मंडी भाव**: प्रमुख राज्यों के दैनिक भाव, **MSP से तुलना** व व्हाट्सएप शेयर।
4. **🩺 एआई फसल डॉक्टर**: पत्ती की फोटो अपलोड करें, तुरंत रोग का नाम, **जैविक व रासायनिक उपचार (दवा व सही खुराक)** पाएं।
5. **📒 किसान खाता-बही**: खाद, बीज, डीजल, लेबर व फसल बिक्री का पूरा हिसाब, **शुद्ध मुनाफा/घाटा** कैलकुलेटर।
6. **🧮 खाद व बीज कैलकुलेटर**: एकड़, बीघा या हेक्टेयर के अनुसार **यूरिया, डीएपी, पोटाश की सटीक बोरी** की गणना।
7. **🏛️ सरकारी योजनाएं पोर्टल**: PM-किसान, फसल बीमा, कुसुम सोलर पंप (60% सब्सिडी), KCC (4% ब्याज)।
8. **🛒 किसान बाज़ार**: बिना बिचौलियों के सीधे फसल, ट्रैक्टर, पशुधन खरीदें व बेचें। किसान को डायरेक्ट कॉल व WhatsApp।
9. **👥 कृषि चौपाल**: साथी किसानों और KVK वैज्ञानिकों के साथ सवाल-जवाब।
10. **🔊 आवाज़ सहायक**: पूरी सलाह और मौसम रिपोर्ट को बोलकर सुनने की सुविधा।
11. **📞 किसान हेल्पलाइन**: 1800-180-1551 (KCC), फसल बीमा व पशु चिकित्सा नंबर।

## ☁️ Cloudflare Pages पर डिप्लॉयमेंट (Deploy on Cloudflare Pages)

चूंकि आपका कोड सीधे आपके GitHub खाते में पुश हो चुका है:
1. **[dash.cloudflare.com](https://dash.cloudflare.com/)** पर जाएं।
2. **Workers & Pages** > **Create application** > **Pages** > **Connect to Git** पर क्लिक करें।
3. अपना GitHub रिपॉजिटरी चुनें: **`aklove4047-cpu/farmer-app`**
4. बिल्ड सेटिंग्स सेट करें:
   - **Framework Preset**: `Vite`
   - **Build Command**: `npm run build`
   - **Build output directory**: `dist`
5. **Save and Deploy** पर क्लिक करें। आपकी वेबसाइट 1 मिनट के भीतर दुनिया भर में लाइव (Live CDN) हो जाएगी!
